# Mantenimiento de architecture.md

`architecture.md` (raíz del repo) es el mapa de referencia rápida del proyecto. Cada vez que termines un cambio no trivial (nueva ruta, nuevo Server Action, cambio de modelo de datos, nueva carpeta/patrón en `lib/` o `components/`, etc.), revisa si `architecture.md` sigue siendo preciso y actualízalo en el mismo trabajo — no como tarea aparte ni solo si el usuario lo pide. Cambios puramente visuales/CSS o de copy no requieren actualizarlo.
